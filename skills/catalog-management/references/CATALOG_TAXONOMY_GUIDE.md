# Guide: Commerce Catalog Taxonomies

This reference guide provides guidelines for designing and categorizing products inside Liferay Commerce.

---

## Standard Taxonomy Schema

Every B2B catalog must structure categories hierarchically:

*   **Catalog Name:** [e.g., Everflow Spare Parts Catalog]
*   **Category Vocabulary Name:** [e.g., Components Classification]
*   **Faceted Specification Key:** [e.g., operating-pressure, diameter-inches]
