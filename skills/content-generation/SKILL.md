# Skill: Content Generation (LLM Synthesis)

## Description
This skill defines standard guidelines for generating highly professional, contextualized, and boardroom-ready marketing copy, catalogs, specifications, and media items for B2B portal demonstrations.

---

## Strict Execution Protocol

You MUST NOT write generic, filler, or "lorem ipsum" text. You MUST adhere to these standard guidelines when generating any content assets:

### 1. The Prospect Brand Mandate
- Analyze the customer's actual brand, industry, and corporate identity.
- Dynamically adapt all generated product records, option templates, specifications, and media text blocks to reflect the prospect's actual context, colors, and industry terminology.

### 2. High-Impact Copy Rules
- Write clear, concise, B2B-specific descriptions (focusing on enterprise value, integrations, and technical parameters).
- Keep descriptions realistic, detailed, and clean, ensuring that the final portal looks "alive" and ready for executive presentations.
